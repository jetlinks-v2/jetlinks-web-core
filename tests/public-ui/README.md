# 公共阅读与编辑组件验收

使用真实 Vue、Ant Design Vue、AIcon、平台样式及公共组件，不访问后端。它是隔离宿主，不代表完整生产 Provider 和业务权限已验证。

示例按字段与选择、单字段保存、整表保存、首次录入、多语言、异步与失败、分区布局分组。页签切换保留各自草稿；顶部可限制内容最大宽度，窄屏仍随可用空间收缩。分区布局分别展示 `ResponsiveSplitter` 的自适应抽屉和 `EqualHeightColumns` 的头部、调宽与手动折叠，分类搜索与详情使用固定且对应的资料；详情头与键值字段复用 `DetailHeader`、`KvGrid`。

“正文自带头部”展示旧页面不声明头部插槽的组合：标题与正文顶端齐平，不生成收放按钮或额外占位。可切换 0／16／24／32px 间距和调宽；核对实际间距、搜索、选择及备注保持正常。收放能力由“带头部分栏”示例验证。

整个示例由一个 `ContentPanel` 提供表面和外框，宽度选项约束该工作区。Tabs 和布局工具栏的结构线贯通外沿；两种分区填满剩余正文，分割线连接头部下沿与底边，面板内容自己保留留白。阅读和表单场景仍在内容内部留白并正常滚动，不给分区再套圆角框或固定高度。公开组合契约见 `src/components/ContentPanel/README.md` 和 `src/components/Splitter/README.md`。

```sh
node --test tests/inlineEditForm.test.mjs tests/inlineEditing.test.mjs tests/publicUiExamples.test.mjs tests/pageHeader.test.mjs
node --test tests/workspacePanels.test.mjs
node --test tests/responsivePanel.test.mjs tests/responsiveSplitter.test.mjs tests/basicProfileSave.test.mjs
node tests/check-workspace-panels.mjs tests/tsconfig.public-ui.json
node_modules/.bin/vite build --config tests/public-ui/vite.config.mjs --configLoader runner
node_modules/.bin/vite --config tests/public-ui/vite.config.mjs --configLoader runner
```

访问 `http://127.0.0.1:9521/`。按页签切换场景，再调整内容最大宽度，核对详情动作及录入列数随容器重排。分区布局的“带头部分栏”使用真实分类搜索与详情；数组与 slot 字段应具有一致样式。单字段保存分别选择成功、返回字段错误、抛出异常，检查错误只显示一次、输入保留、Esc 取消及重试；用键盘选择负责人，核对实际 combobox 的标签。候选含说明，收起标签保持短名称。折叠入口优先融入主区头部，左区搜索独立；收起后左列归零，入口、焦点及输入保留遵循公共布局契约。

这是本地模拟页，保存不访问后端，刷新后恢复。字段请求次数包含失败，不代表成功写入。`Editable` 只提交值，`InputEditable save` 和详情模式模拟单字段请求，首次录入及通用 Form 的字段确认只进入各自草稿，整表动作才接受保存；这些示例不共用记录状态。只读和禁用演示的是客户端行为，不能作为服务端权限证据。不得输入真实凭据。

## 分区数据列表

“分区数据列表”以运行监测为模拟业务，复用公共分区、ConditionFilter、状态徽标、详情列表和卡片，填满同一验收表面。左侧分组、右侧头部同行；数据在内容区按需追加，总数及状态分布独立统计，局部详情用骨架屏等待。表格比较多点位，卡片展示当前值、单位、参考范围、异常及短趋势；详细来源在抽屉查看。

数量入口使用状态图标、文字和数字徽标。点击正常／异常／离线，在 ConditionFilter 中回显同一状态条件；切换替换该状态，再次点击取消，“全部”清除该维度，保留分组与其他条件。分布按分组及其余查询条件统计，排除同级状态筛选，便于继续比较；混合 OR 表达式保留整体，通过 AND 加入快捷状态，不拆写其含义。手工修改、清空条件后，按钮选中态由同一模型推导。示例消费 `change.terms` 的标准转换结果，模拟端理解转义后的 like 条件，不将原始编辑草稿直接当作生效查询。不要只用颜色辨认状态。

数据和参考范围均为本地演示，异步生成器模拟逐条返回、独立统计、按批详情补查与取消；不调用真实 `/_query/no-paging` 或设备服务，不证明生产鉴权、传输背压、真实阈值或虚拟渲染已接通。新增模型回归入口为 `node --test tests/public-ui/monitoring/model.test.mjs`。浏览器需核对徽标筛选与清空、慢统计不阻塞列表、长内容滚动、详情及 390px 布局。

“多语言”的点位名称和“字段与选择”的来源名称覆盖公共文字编辑：输入长短内容，核对宽度随动至配置上限、字体与基线不跳动、hover / focus 下划线及 Esc 恢复。多语言入口承接文字草稿，面板按平台支持语言配置显示；取消、外部关闭不提交，确认一次更新文字与翻译。用 Tab 进入多语言按钮并打开面板，检查输入焦点、Esc 关闭及焦点返回。

“多语言”的内容说明覆盖多行原位编辑：阅读保留段落，进入编辑后内容区宽度与初始高度保持，Enter 换行、普通失焦保留草稿，Ctrl / Cmd + Enter 保存、Esc 取消；内容增长至高度上限后内部滚动。翻译面板用语言 Tabs，切换后保留各语言草稿，全部校验后一次确认；隐藏语言校验失败需切回对应页签并聚焦错误字段。“表单多语言输入”验证独立 Modal 复用同一编辑内容，保留主输入值与翻译映射。

两区之间的真实分割线已启用调宽：拖动、方向键和点击操作共用边界，Esc 回滚拖动，双击恢复初始宽度。调整后折叠再展开应保留宽度与搜索值；无业务页 CSS 或模拟拖动代码。

“分区布局”的“自适应分区”示例直接使用 `ResponsiveSplitter`，可切换左右 / 上下分区；默认尺寸、像素边界和宿主尺寸共同约束布局。分割条默认仅保留连续细线，hover 显示轻量把手，不弹出尺寸菜单。方向键、Home / End 调整尺寸，双击或 Enter / Space 复位；Esc 撤销拖动。折叠后点击握柄或 Enter / Space 恢复原尺寸。折叠入口使用公共 `PanelCollapseButton`，位于布局外的工作区工具栏，与“处理工作台”标题同行，关联真实导航区域 ID；图标随布局方向变化。

工作台通过公共 `ResponsiveSplitter` 区分手动偏好与临时适配。左右布局切到 390px 内容容器后自动收起任务列表，主区不再参与双面板调宽，边缘保留独立12px恢复槽；点击入口或向内拖动均可打开本工作区内的临时抽屉。拖动预览跟随指针，超过一半确认，回拉到40%撤销；短拖、Esc、捕获丢失和布局切换均返回隐藏，不写回宽布局偏好。选择任务后关闭并将焦点转到详情标题，Esc / 关闭返回入口。扩大到 700px 时：原先展开的列表恢复，手动收起的仍然收起；临时抽屉不会自动打开。核对搜索草稿、选中项、DOM 实例、原尺寸和滚动位置经过切换仍保留；在抽屉内聚焦搜索时变宽，应保留合理焦点。上下布局按可用高度与最小尺寸预算适配，恢复槽和拖动方向随之旋转。

“选择与日期”覆盖单选、多选、日期与范围：弹层拥有原生 Enter / Esc，只有完整选择发出 change；多选在保存前只维护草稿，普通失焦保留。用键盘和鼠标分别核对第一次 Esc 关闭弹层、下一次取消编辑。“多类型原位编辑”覆盖数字、Select、Switch、复合上下限和多行：复合字段内部移动焦点不写入，非法整体值保留草稿；多行失焦不保存，Ctrl / Cmd + Enter 或按钮确认，取消回退。

工作台已开启拖动折叠。左右分区在 160px 最小宽度处继续拖动，请求尺寸小于 80px 时显示两端渐隐的内缘阴影，面板仍保持 160px；拖回 96px 以上撤销意图，松手才用平台快速过渡收起。分隔器独立占用 12px 拖拽槽，核对展开、折叠和揭开过程中均不覆盖内容；折叠后整条线隐藏，只保留槽中央的握柄。从边缘向右拖会逐步揭开面板，松手后应用合法尺寸，短距离或 Esc 撤销。展开过程中保留搜索草稿，工具栏按钮继续恢复保留的尺寸。上下分区使用同样的 Y 轴交互和独立横槽。减少动态效果时不播放过渡。
