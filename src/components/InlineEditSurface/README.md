# InlineEditSurface

保留阅读入口的尺寸，将同一份内容在原位置展开；可用宽度来自入口最近的定位容器，单行高度预算至少32px。宽度或高度越界时增加悬浮表面，并限制在视口内。内容不撑开邻居，不因原位/悬浮切换重建编辑器。

从`@jetlinks-web-core/components/InlineEditSurface`导入。`open`控制展开，`label`命名内容分组。默认插槽提供内容，可选`display`插槽提供阅读入口，并接收`contentId`供按钮的aria-controls使用；入口自行绑定aria-expanded。没有display时，内容直接参与原布局。

展开内容通过Teleport脱离裁切容器，隐藏的阅读入口继续占位。关闭只隐藏内容，不负责放弃草稿；草稿、显式保存/取消、错误、权限及候选浮层由宿主维护。展开时聚焦首个可用输入或按钮，关闭后归还入口焦点；布局切换不重新聚焦。复杂控件沿原组件弹层及确认方式使用，表面不接管业务键盘或失焦提交。

占位和定位准备使用opacity与inert隔离交互，避免基础输入控件的visibility过渡阻断首次聚焦；入口被折叠或移出视口时隐藏编辑表面，保留宿主草稿。

首个消费者为设备和边缘节点的标签集合及单项编辑。原始回显、值类型和持久化均由device-manager-ui负责。
