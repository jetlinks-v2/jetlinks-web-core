# PanelResizeHandle

二列 Grid 工作区的右侧分界线，从 core 组件入口具名导出，不做全局注册。父级持有 `v-model` 宽度并用于第二列，传入 `container` 工作区元素和已翻译的 `aria-label`；分界线与右栏共同定位在第二列第一行。

`limits` 可指定 `min`（默认320）、`max`（640）、`contentMin`（360）及 `initial`（360）。最大宽度受工作区剩余宽度限制；父级在容器不足两栏时负责切回单栏并隐藏分界线。原有折叠操作由父级管理，组件不读写业务配置或存储。

向左拖动增宽右栏，左右键微调16px，Home/End使用边界，双击恢复初始宽度。Esc或指针取消恢复本次拖动前宽度；卸载释放指针捕获。视觉宽度为10px，以覆盖分界线的方式命中，不额外占用一列。
