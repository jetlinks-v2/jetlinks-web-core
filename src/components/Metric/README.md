# 指标计算组件

`MetricTemplateManager` 管理模板、发布与模拟；`MetricWorkspace`、`MetricPanel` 和 `MetricResult` 展示业务配置及结果。业务模块声明对象维度、来源选择和前端参考模板，公共层不依赖设备或空间页面。

结果展示使用 `/metric/configs/{id}/result` 及其 `/template` 只读视图，不依赖完整配置或输入来源的管理权限。成员汇总直接使用后端返回的历史分组，不预读全量成员目录；当前结果钻取使用宿主成员分页，保留所选口径和统计时段。

对象工作区先展示指标结果，“添加指标”统一提供新建计算和添加已有指标两种用途；管理操作按需展开。首次空态用简短场景说明和两种用途的操作卡片引导，复用同一添加流程；结果面板通过 empty 插槽承载宿主引导，不重复提供通用添加按钮。

查看方式与统计范围使用无边框选择器，展开项复用 SelectOption 的语义图标、名称及次级短说明，选中态只保留图标与名称；输入字段仍按录入任务呈现。更新方式支持实时展示每次新结果及 1／5／15 秒合并展示，默认合并 1 秒；反显的是实际推送合并间隔，不表示轮询查询，也不改变指标计算周期。来源绑定行的图标保持固有宽度，仅名称占用剩余空间。

结果复用平台 WebSocket 单例连接，每个可见指标独立订阅历史与实时结果。滚动只取消离屏项并新增进入视口的订阅，历史逐条展示，首次加载使用卡片骨架。客户端重连重放有效订阅，服务端 `reset` 开始新读取代；撤权清理对应结果，单项失败不影响其他订阅。`metricNdjsonWatchResults` 保留批量 HTTP 流式入口，消费同一结果帧，页面不同时启动两种传输。

添加已有指标先选择来源对象，再选择具体输出；承接指标的对象不作为默认来源。关联卡片复用原指标的展示配置、值和历史组件，并保留来源及添加位置。历史按配置和实际来源对象隔离、按可见卡片有界读取；普通刷新保留已有布局，只有首次读取使用骨架，切换对象或确认撤权后清理旧结果。

“指标／汇总统计”复用平台页签。汇总只有一个入口，直接选择统计范围、指标和时段，再在结果卡片上切换平均值、最高最低值等可用统计。页面不常驻功能介绍、场景示例或统计方式说明，口径放在帮助气泡。有已添加的指标时默认汇总这些结果，也可切换到对象声明的下级或关联对象范围；两类范围明确区分，不把添加指标等同于添加成员。原指标页不再提供另一套折叠汇总。

两类范围复用同一汇总状态、筛选、结果卡片和刷新策略，分别调用已有的关联汇总或成员汇总接口。关联汇总按来源对象类型分开，包含下级添加的指标、由后端去重；仅成员范围提供声明允许的层级切换与逐对象钻取。汇总使用所选时段内各对象的末次记录，参与数量仅表示有记录的对象，不等于全部成员；统计切换只展示服务端允许的操作，并同步改变结果与趋势。“查看当前结果”读取最新值，明确区别于历史贡献明细，返回保留筛选与时段。仅最新值、无成员、无可见指标及无历史按授权查询事实展示不同提示，不在浏览器合计成员或新增计算。

指标公式通过 `template/TemplateMathEditor.vue` 适配到 core 的 `MathExpressionEditor`，统一使用就地候选、原生选区、嵌套分支、参数提示和 LaTeX 交换。宿主提供输入、上游计算、模板参数及其字段路径、类型、单位和显示说明；函数目录由 `/metric/templates/expression/functions` 按模板查询权限读取，并沿用后端纯函数声明和国际化。

编辑后保存 `StructuredExpression` 与引用依赖。已有源码只在可完整转换时投影为数学公式，查看不写回；仅提供公式编辑，无法投影的历史源码保留数据，并提示从完整配置查看。反显和执行解释复用 `ExpressionView`、`ExpressionWorkspace` 及同一目录。模拟继续调用指标模板或配置的后端试算接口，浏览器不计算结果。

“规则与计算”下的“指标管理”和“指标模板”入口由规则引擎模块的 `baseMenu.ts` 注册，再通过菜单初始化写入。设备、空间等业务模块提供对象维度、数据来源和导航扩展，接口请求沿运行时原有授权上下文。

对象类型发现收敛：工作区及来源选择只展示后端 `/relation/types` 实际声明、且当前前端模块及权限可用的类型；模块注册只提供呈现与导航，不能凭空补充后端类型。目录按当前身份读取，加载及失败时不发起对象指标查询，失败提供重试；成功返回空目录与读取失败分开展示。验证覆盖缺失来源、空目录、失败重试与身份切换的迟到响应。

状态缩略图和详情都按结果的真实计算时间绘制离散采样，不将相邻同值采样补成连续状态。缩略图最多显示最近 60 次采样，并标明实际样本时段；详情保留完整查询时段和全部已返回采样。只有后端确认的状态区间使用持续色带。验证覆盖不等间隔采样、空缺与详情原始时间戳。
算法说明只消费后端版本化 `documentation`：下拉弱化行使用共享 `LatexView` 排版公式，计算图例展示固定算例的输入、具体计算和预期结果。没有声明说明时不猜算法类型、不生成图例；算例参数独立于编辑草稿，当前参数的实际结果由模板试算提供。
