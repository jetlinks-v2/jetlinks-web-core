# 指标结果与查询组件

公共层提供 `MetricResult`、`MetricValueView`、历史视图、只读计算图、集合查询与汇总统计。共享类型、对象维度、来源选择和呈现扩展沿用现有模块注册机制。

模板设计、发布、试算、配置编辑、关联管理和管理工作区由 `rule-engine-manager-ui/components/Metric` 提供。对象页面通过 `RemoteComponent` 加载业务模块公开注册的 `MetricScopePanel`；core 不导入业务模块实现。`metricApi` 只实现读取请求，`MetricReadApi` 描述查询能力，完整 `MetricApi` 管理契约由业务模块实现。

结果展示使用 `/metric/configs/{id}/result` 及其 `/template` 只读视图，遵循实际结果对象的读取权限。需要输入快照的计算过程继续使用独立授权入口。只读公式与管理编辑器共用 `template/formula.ts` 中的引用转换，展示不会加载编辑或试算 hooks。

成员和关联汇总复用同一筛选、卡片与刷新策略。先读取 `/_aggregate/templates` 的授权轻量模板目录，恢复模板选择，再把 `templateIds` 传到统计接口；筛选后的统计结果不替换候选目录。目录或统计确认撤权后清除已有结果，切换对象、范围及身份后丢弃迟到响应。

汇总与趋势来自所选时段内的真实历史记录，不由浏览器合计成员或补算。相同对象、模板和可比较贡献口径只计一次，空桶保持缺口；历史参与数量不表示全部成员。只有成员范围支持宿主分页钻取，“查看当前结果”与历史贡献时段分别表达。

结果复用平台 WebSocket 单例，每个可见指标订阅历史和实时结果。离屏项取消订阅，重连重放有效请求，服务端 `reset` 开始新读取代；撤权清除对应结果，单项失败不影响其他订阅。`metricNdjsonWatchResults` 提供消费同一帧协议的批量 HTTP 流式入口。

状态缩略图和详情按真实计算时间绘制离散采样，不把同值样本补成连续区间。只有服务端确认的状态区间使用持续色带。数值、单位、统计语义和算法说明均消费后端版本化声明；浏览器不推断算法或质量。
