# 公式编辑组件

MathExpressionEditor 与 MathExpressionView 共用结构化表达式及 MathLive 反显；宿主通过 context 声明变量、类型、枚举和函数目录，组件不执行业务计算。

- 工具栏的变量、值、函数、条件以及公式内容中的变量、函数都在当前光标或点击内容旁打开候选，切换候选时保留选区。替换目标显示原生选区，空位插入显示原生光标；候选获得焦点时仍保留反馈，取消后恢复原选区。变量选择替换数据项；函数选择保留已有参数，只有用户显式选区才作为新函数的第一个参数。
- 候选浮层复用 Ant Design 的视口避让，挂载在当前弹窗内；展开、收起时关闭旧候选，避免跨浮层保留旧位置。
- 变量、值、函数与条件共用 ExpressionCandidateMenu，搜索与结果在同一个浮层内；宿主只提供候选分组、图标、说明与可用性，统一处理过滤、空结果和目录错误。内联编辑使用紧凑尺寸，放大编辑保留更多空间；搜索不改变面板尺寸，自动聚焦不滚动宿主页面。
- 公式内容的右键菜单提供变量、值、函数和条件的就地候选入口，按原选区及类型约束筛选；同时提供撤销、重做、复制／粘贴 LaTeX 和全选。搜索框、源码文本区保留正常文本编辑菜单。
- 复制支持选区与整式；粘贴复用当前解析及类型校验。LaTeX 传递保留变量标识、字段路径和函数语义，保存及执行仍使用结构化表达式。
