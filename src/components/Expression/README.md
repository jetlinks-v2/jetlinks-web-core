# 公式编辑组件

MathExpressionEditor 与 MathExpressionView 共用结构化表达式及 MathLive 反显；宿主通过 context 声明变量、类型、枚举和函数目录，组件不执行业务计算。

- 工具栏与公式内容中的变量、函数都在当前光标或点击内容旁打开搜索候选，切换候选时保留选区。变量选择替换数据项；函数选择保留已有参数，显式选区可作为新函数的第一个参数。
- 候选浮层复用 Ant Design 的视口避让，挂载在当前弹窗内；展开、收起时关闭旧候选，避免跨浮层保留旧位置。
- 公式内容的右键菜单提供撤销、重做、复制／粘贴 LaTeX 和全选。搜索框、源码文本区保留正常文本编辑菜单。
- 复制支持选区与整式；粘贴复用当前解析及类型校验。LaTeX 传递保留变量标识、字段路径和函数语义，保存及执行仍使用结构化表达式。
