# AutoFitText

固定空间中的单行标签。复用 `useContentFit`，按实际文本宽度调整字号，不缩小图标、点击区域或控件高度。语言、容器尺寸及字体加载变化后重新测量，合并到布局帧，不轮询。

通过 `@jetlinks-web-core/components` 具名导入。`text` 为完整文本，`maxSize` 默认 14px，`minSize` 默认 12px；字号到下限后仍容纳不下时省略，默认使用标准 Tooltip 展示全文。已有运行摘要或完整提示的宿主可传 `tooltip=false`，避免重叠浮层。全文保留在 DOM 中，不改变宿主的可访问名称。

宿主须提供可收缩的有限宽度：Flex／Grid 项设置 `min-width:0`，图标和必要动作不参与收缩，文本占剩余空间。按钮和分段选择的尺寸归控件管理；正文、长名称和可换行说明优先沿用自然排版或省略，不机械缩小全页文字。字体尺寸由场景设置可读上下限，不依据语言名称特调。

组件实例暴露 `preferredWidth`（按 `maxSize` 测得的自然宽度，含测量余量）与 `element`（文本容器），供分区按内容计算默认宽度；宿主仍负责尺寸上下限及保留手动调整。`useContentFit` 同时提供 `overflowing`，供固定空间标签判断是否需要全文提示。
