# 左侧栏内容统一样式

## 1. 目标与当前结论

把 7 个运行时页面左侧内容区统一为同一种「标题/分段器 → 搜索 → 内容 → 底部新增按钮」结构，参考图见 `runtime-ui/参考图片/`：

- `Sidebar-6-空间列表.webp`：无分段器，顶部保留标题
- `Sidebar-5-按设备按空间.webp`：有分段器，顶部不出现标题

统一契约：

| 规则 | 结论 |
| --- | --- |
| 标题 | 左侧栏有分段器时不渲染标题；无分段器时保留标题 |
| 搜索框 | 统一使用 `a-input`，左侧 `#prefix` 插槽固定放 `icon-gaojingzhongxin-zhinengsousuo-sousuo` |
| 新增按钮 | 存在时统一下沉到左侧栏底部，`block` 撑满，默认按钮样式（不再用 primary/dashed/自定义蓝色） |
| 间距 | 标题/分段器、搜索框、内容区、新增按钮之间统一 `gap: var(--space-4)`（16px） |
| 内边距 | 子元素不再各自设置纵向 padding，纵向间距全部由容器 `gap` 提供 |

## 3. 明确不做

- 不修改任何接口、查询参数、权限、i18n 文案和业务事件。
- 不新增搜索能力：设备列表（区域/分组分段器）继续没有搜索框，只统一已有搜索框样式。
- 不改分段器本身的样式与选项文案。
- 不处理页面级 `padding` 归零（`meta.contentPanel.padding` / 面板内边距），本次按用户要求「先不管」，与 `jetlinks-web-core/docs/页面内容面板与页面头部插槽.md` 的迁移分开推进。
- 不改 `ui/`（运营端）。

## 4. 实施要点

1. **空间配置**：`AreaTreePanel` 的搜索前缀图标换成统一图标；面板改为 `gap: var(--space-4)` + `padding: 0 var(--space-4)`，标题头去掉 `40px` 固定高度与下边框，搜索/树/底部按钮不再各自带纵向 padding。
2. **产品列表**：`ProductCategoryTree` 补标题「产品分类」（复用既有 i18n key `Product.index.660348-36`），栅格布局改为 flex 纵向 + `gap: var(--space-4)`，内容区 `flex: 1`，新增分类按钮改为默认 `block` 按钮。
3. **设备列表**：`IotDeviceScopeSidebar` 只把 `--space-3/--space-2` 间距统一为 `--space-4`，新增分组按钮去掉 `type="dashed"`。
4. **视频列表**：`MediaDeviceTree` 搜索前缀由可点击 `button + SearchOutlined` 改为统一图标（搜索仍由 `update:value` / `press-enter` 触发），并删除随之失效的 `.mdt__search-action` 样式。
5. **分屏播放**：`VideoMonitorWallSidebar` 统一搜索图标；底部按钮改用 `#icon` 插槽、去掉自定义蓝色按钮样式；`.vmw-sidebar__footer` 去掉 `padding-top`，间距交给 `gap`。
6. **目录管理**：`Catalog/Left` 把 `a-input-search` 换成带前缀图标的 `a-input`，新增按钮从搜索框下方移动到左栏底部，树区域改为 `flex: 1` 滚动、空态居中。
7. **物联告警**：左栏搜索换成带前缀图标的 `a-input`，左右两栏 `gap` 统一为 `--space-4`，标题字重统一为 `600`，新增规则按钮去掉自定义高度/圆角。

## 5. 验证结果

- 模块构建（`pnpm -F jetlinks-web-core build -- --module-name <module>`）：`jetlinks-media-ui` ✓ 24.59s、`device-manager-ui` ✓ 28.74s、`jetlinks-space-ui` ✓ 21.42s，均构建成功。
- `vue-tsc --noEmit`（`jetlinks-media-ui` / `device-manager-ui` / `jetlinks-space-ui`）：改动文件零报错；日志中的报错全部落在未改动的历史文件（`views/Stream/index.vue`、`views/video/composables/useJessibucaRuntime.ts`、`views/space/WK-Situation/*`、`views/link/Certificate/type.d.ts` 等）。
- `jetlinks-media-ui` 单测：`170/173` 通过；唯一失败 `views/video/services/videoAreaBindings.integration.test.mjs` 依赖真实后端数据，与本次改动无关。
- `device-manager-ui` 单测：`41/42` 通过；失败项 `tests/deviceDetailAgentLifecycle.test.mjs` 与本次改动无关。
- `jetlinks-space-ui` 单测：`57/60` 通过；失败项均为 `<ContentPanel>` 迁移断言（`areaManagementPresentation`、`spaceMenuPermissions`）与 `areaFloorplanMarkerName`，属于页面容器迁移的既有失败。
- `MediaDeviceTree` 专项单测：`9 pass / 1 skipped`（skip 为 jsdom 环境缺失）。

## 6. 待确认点

- 新增按钮统一为「默认按钮」是按参考图（灰字、浅边框）处理的；`AreaTreePanel` / `VideoMonitorWallSidebar` 原先的自定义蓝色按钮样式已移除。若设计实际要保留蓝色描边按钮，需要回滚这两个组件的按钮样式并另行统一其余 4 处。
- 「统一没有内边距」尚未实施：页面容器 `margin` / `ContentPanel` 内边距未调整，当前保留各页面既有留白。
